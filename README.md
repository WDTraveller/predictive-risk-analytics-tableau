# Предиктивная аналитика и оценка финансовых рисков (Python + Tableau)

Командный аналитический проект по построению модели машинного обучения и интерактивной BI-панели для вероятностной оценки исходов и принятия решений на основе данных (Data-Driven Decision Making).

## Бизнес-задача и ценность подхода
Классический бинарный прогноз («да / нет») не позволяет оценивать степень неопределённости и управлять финансовым риском. В рамках проекта реализован переход к **вероятностному моделированию**: алгоритм рассчитывает распределение вероятностей для всех возможных исходов события, что позволяет сопоставлять расчётную вероятность с рыночной оценкой и находить недооценённые сценарии с положительным математическим ожиданием (ROI).

## Ключевые параметры и стек
* **Объём данных:** 25 979 исторических наблюдений по 48 параметрам (очистка, агрегация и конструирование признаков в Python).
* **Модель:** `RandomForestClassifier` (100 деревьев, `scikit-learn`), обученная на трёх ключевых факторах: разница базового рейтинга, динамика формы за последние 5 периодов и показатель уязвимости.
* **Визуализация:** Интерактивный аналитический дашборд в **Tableau** для сценарного анализа в реальном времени.
* **Инструменты:** Python (`pandas`, `scikit-learn`), Excel, Tableau BI.

## Структура репозитория
* `predictive_model.ipynb` — Jupyter Notebook с полным пайплайном обработки данных, генерацией признаков, обучением модели Random Forest и расчётом вероятностей.
* `final_dataset.csv` — подготовленный датасет (25 979 записей, 48 признаков: исторические результаты, рейтинги, динамика показателей и рыночные котировки), используемый для обучения модели и расчёта прогнозов.
* `presentation.pdf` — презентация проекта с методологией, сравнением подходов, примером расчёта и дорожной картой развития (Roadmap).
* `dashboard.twbx` — исходный файл интерактивной рабочей книги Tableau.
